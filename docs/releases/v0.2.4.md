Keep generated projects focused on their own context by separating the Control Plane product example from the initialization template.

Highlights:
- Stop copying `examples/file-organizer/` into newly initialized projects
- Keep the File Organizer example in the Control Plane product repository as a single reference source
- Remove the product example from generated-project validation requirements
- Verify through the packed artifact integration test that generated projects do not contain product examples

Migration:
Existing generated projects are not updated automatically. Projects that do not need the File Organizer example may remove `examples/file-organizer/` and its required-file and heading checks from `scripts/check.sh` and `scripts/check.ps1` together. Do not add the example to `.gitignore` while validation still requires it.
