# v0.4.0

Explicit CLI decisions, recoverable approval updates, and shared Bash / PowerShell completion.

Highlights:

- Approve configured Bootstrap items and individual ADRs with `control-plane approve`.
- Reject Proposed ADRs with a literal, reviewable `--reason`; Architecture approval remains a separate operation.
- Preserve adopted ADR content, verify upstream revisions, and diagnose incomplete replacement relationships with `doctor` and `next`.
- Serialize CLI updates with an exclusive lock and recover interrupted writes explicitly with `recover --complete` or `--rollback`.
- Generate optional Bash 4+ and PowerShell 7.2+ Tab completion from the CLI command registry and Project state, without changing profiles or writing Project files.
- New Projects use schema v2 and the `product-overview` item / Product Overview label. Existing IDs are not silently renamed.

Migration:

- Existing Projects are not automatically updated. Install this CLI version, review your Bootstrap definition, and run `control-plane migrate`. This preserves item IDs and upstream approval records while requiring Architecture re-review.
- Review and approve changed upstream documents, then explicitly record each existing Accepted / Superseded ADR with `control-plane migrate adr NNNN`. Missing or ambiguous relationships must be repaired; historical approval is not reconstructed.
- Reflect adopted decisions in `ARCHITECTURE.md`, approve the configured Architecture item, and run `control-plane check`.
- Replace an old `record-approval.mjs` with the adapter from the new Template and review its Bootstrap Skill / workflows / ADR instructions. The new adapter delegates to the installed CLI; do not retain the old direct state-writing implementation.
- Recovery, manual Template updates, optional item-ID renaming, and shell activation / removal instructions are in the [CLI README](https://github.com/smallfield5656/control-plane/blob/v0.4.0/packages/cli/README.md).

Node.js 22+ remains required. No runtime dependencies, network calls, or AI API access were added to the CLI.
