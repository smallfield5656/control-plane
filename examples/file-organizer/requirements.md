# Requirements

## REQ-001: Folder selection

ユーザーは整理対象のフォルダを選択できる。

### Acceptance Criteria

- ローカルフォルダを選択できる。
- 選択をキャンセルしてもエラーにならない。
- 存在しないパスは処理対象にしない。

## REQ-002: Preview

ユーザーは実行前に、どのファイルがどの分類先へ移動されるか確認できる。

### Acceptance Criteria

- 各ファイルの現在位置と移動先が表示される。
- 実行前に対象から除外できる。

## REQ-003: Organize files

ユーザーは確認済みの対象について、拡張子ごとのサブフォルダへ移動を実行できる。

### Acceptance Criteria

- 拡張子ごとに分類先を決定する。
- 同名ファイルが存在する場合は上書きしない。
- 一部の移動に失敗しても、失敗したファイルを識別できる。
