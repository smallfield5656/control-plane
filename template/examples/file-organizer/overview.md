# Product Overview

## Problem

Windowsでダウンロードしたファイルが1つのフォルダに溜まり、種類ごとに手作業で整理するのが面倒である。

## Users

- Windows 11を利用する個人ユーザー。
- 開発者ではなく、CLI操作を前提としない。

## Goals

- 指定フォルダ内のファイルを種類ごとに整理できる。
- 実行前に移動内容を確認できる。
- 誤操作時の影響を小さくする。

## Non-Goals

- クラウド同期。
- 複数PC間の設定同期。
- 高度なルールエンジン。

## Success Criteria

- 1000件程度のファイルを実用的な時間で分類できる。
- ユーザーが移動前に対象を確認できる。
- 通常利用で外部サーバーを必要としない。
