# Constraints

## Platform

- Windows 11を対象とする。
- Desktop appとして配布する。

## Distribution

- 利用者にNode.jsやPythonの事前インストールを要求しない。
- 単独で配布可能なApplication packageを作れること。

## Network

- 通常利用でInternet connectionを必須にしない。

## Data

- 対象ファイルを外部サーバーへ送信しない。
- ファイル内容の解析はローカルで完結する。

## Operations

- 専用Serverの運用を必要としない。
- 個人または小規模Teamで保守できること。

## Project Stage

- Productionを前提とする。
- 数年間の保守を想定する。
